Issue #83 · step 1 · 2026-11-23

Artifact Store Spike

Two cloud sessions exchanged a question, an answer and an ack through the database of one private Artifact. They used no local store and no orch. The local session read the database only.

Recommendation

Do not use the Artifact database as the remote store behind IRepository. The supervisor, orch and the hooks are C# and TypeScript processes. They cannot call the database, because only a Claude tool or a page can reach it. Go to the next option: the H5 store API through the D2 tunnel, or a Notion store (H6).

The database can be a mailbox for cloud sessions with no tunnel. A relay session then copies its envelopes into the local store.

The exchange took 31 s, and the poll set most of it
