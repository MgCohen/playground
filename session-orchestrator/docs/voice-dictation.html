Q3. Which speech engine is acceptable?

open
Question
Free browser or Windows engines, a paid cloud speech service, or a local model on this PC?
Context
The free browser engine probably does not work in the tray (P1) and needs HTTPS on the phone (P2). A cloud service costs about 0.006 USD a minute, and the audio goes to the provider. A local Whisper model has no cost and no upload, but it uses CPU or GPU.
Options
Free engines only (browser, Win+H, phone keyboard) · cloud service through the supervisor · local Whisper in the supervisor · cloud first, local model later
Recommendation
local Whisper In the supervisor, if this PC has enough power; else a cloud service. One engine on the server works the same in the tray and on the phone, and it detects the language.
