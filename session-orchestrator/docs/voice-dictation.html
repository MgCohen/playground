Why the Claude dictation is not an option
  • Claude Code sends the audio to Anthropic servers. It needs a Claude.ai sign-in.
  • The documentation gives no public API or SDK for other apps.
  • A connection to the internal endpoint with your sign-in token is not supported. It can stop working on any update, and it can break the terms of use.
  • It also stops a recording after 2 minutes, or after 15 seconds of silence. Your dictations are up to 5 minutes.
  • The transcription does not use Claude messages or tokens. Thus no other paid plan of Claude gives this service.

Does Anthropic give a speech service?

no
  • The Claude API accepts text, images and documents. It has no audio input and no transcription endpoint.
  • The dictation of Claude Code, the Claude app and Remote Control uses an internal Anthropic service. Only Anthropic apps can use it.
  • Thus no option uses your Anthropic account. Orca does not use it either.

  • The tray records the audio with the browser recorder (getUserMedia). WebView2 allows the mic, and the tray host can allow it with no prompt.
  • The supervisor changes the audio into text with a local model on the GPU. A cloud service with your own key is a second choice in the settings.
  • The Android app uses the engine of the phone, as Orca does. The audio stays on the phone.
  • On a phone browser, the mic needs HTTPS. Until the tunnel, the mic key of the phone keyboard covers the phone browser.
