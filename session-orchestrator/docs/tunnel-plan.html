Orchestrator Tunnel Plan

Decision (user, 2026-11-17): Cloudflare Tunnel + Access, the same as for the runner and the inbox. The build runs on the user's own PC, not on this borrowed PC.

Plan: a named Cloudflare Tunnel, run as a Windows service, sends https://orch.<domain> to a second supervisor port. Cloudflare Access signs in one email address before each request.

Cost: US$0. The plan uses the Cloudflare account, the domain and the Access sign-in of the runner and the inbox again.

The supervisor checks the Access token on the tunnel port. Local tools keep port 7777 with no change.

The phone reaches the supervisor through Cloudflare, with no open port at home

Six steps: three for the user, two for the code, one shared test

UserThe user does it in the Cloudflare dashboard or as administrator. CodeA session does it in this repository.

  1. UserIn the account of the runner and the inbox, make the Access application orch.<domain> first. Use the same login method. Policy: Allow, include your email only. Session: 30 days. Copy the AUD tag.
  2. CodeAdd the tunnel port and the Access token check (tab Code). Merge it before step 3.
  3. UserMake a remote-managed tunnel. Add the route orch.<domain> → http://127.0.0.1:7778. Enable "Protect with Access".
  4. UserIn an administrator prompt, run cloudflared.exe service install <TUNNEL_TOKEN>.
  5. CodeSet ORCH_ACCESS_TEAM, ORCH_ACCESS_AUD and ORCH_TUNNEL_PORT in the supervisor start. Record the setup in know-how.md.
  6. Code+ UserTest on the phone with Wi-Fi off: sign-in, answer a card, a review, the mic, a reconnect after a cloudflared restart.
Make the Access application before the route. A route with no Access application is open to all of the Internet.

The tunnel token and the Cloudflare password are secrets. Keep them in 1Password. The team name and the AUD tag are not secrets.

One new port with a token check; port 7777 stays as it is

cloudflared connects from 127.0.0.1. So the supervisor cannot use the client address to tell a phone from a local tool. It uses the local port.

Notes

  • Tailscale Personal is free for non-commercial use, with 6 users. The phone app takes the VPN slot of the phone.
  • A Quick Tunnel is for tests. Cloudflare gives no uptime promise, and the link changes after each restart.
  • A cloud environment can run cloudflared: it needs only outbound traffic and the token. The supervisor drives the desktop app on this PC, so the tunnel stays on this PC.
