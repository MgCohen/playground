Add a template

  1. Write the folder, for example in the scratchpad. orch template new test-result writes a skeleton.
  2. orch template check <folder> runs the checks below.
  3. orch template add <folder> checks again and copies the folder to <store>/templates/test-result/.
  4. The supervisor sees the change and loads the template set again. The UI shows the kind at once.
  5. Sessions get the tool mcp__orch__<tool.name> at the next plugin load (hot reload).

Remove a template

Only an added template can be removed. Old messages of that kind stay in the stream. The UI shows them with the fallback model: each field as a text block. orch template add of the same folder restores the look.
