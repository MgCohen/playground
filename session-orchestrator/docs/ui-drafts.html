Draft 1

Workflow run page

One page for one run of a workflow. The order on the page: where the run is, the graph, the current step, the possible next steps, then the history. The page bar holds the page actions; the corner button (E-1) holds the actions of the waiting question.

Pick the top part

A shows loops and branches (C1: a graph with one entry and no fixed exit). B is short, but it cannot show a loop. With A, a tap on a node can open that step's history.

Open questions

  • Progress: visited steps, or steps on the shortest path to done? A loop makes "3 of 6" vague.
  • Where does the page live: under the owner session (as here), or as its own tab "Runs"?
  • Large graphs: zoom and pan, or a list of step groups?
