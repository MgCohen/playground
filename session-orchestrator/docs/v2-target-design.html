V2 Target Design

Each page and each list of the app is a view of one query of the event stream. A composer joins the view template, the content template of each kind and the query result into one view model, off the UI thread. The page renders it only with design system components. One navigator owns where the user is, and each motion is a step of a state transition. The diagnosis is on the V2 Visual Restart page.
