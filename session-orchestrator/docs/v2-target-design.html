V2 Target Design

Each page and each list of the app is a view of one query of the event stream. A composer joins the view template, the content template of each kind and the query result into one view model, off the UI thread. The page renders it only with design system components. One navigator owns where the user is, and each motion is a step of a state transition. The diagnosis is on the V2 Visual Restart page.

D2Which base do we copy and own?Recommendation: the system of Web Awesome, with Razor components. No default
Context

You want own components, from a base that we copy one time and do not follow. The comparison is on tab 5 · Design system.

  • B: Web Awesome, all. Use the web components of vsa-design. The AGENTS.md rule must change.
  • C: Blazor Blueprint Primitives. Copy the Razor behavior parts that we need. Use our own look.
  • D: MudBlazor. Copy Razor components and replace the Material look.
Recommend

A. It keeps the structure, docs and guidelines that you named. It leaves out the Lit code and its build. The cost: we write and test the behavior of each component. On a phone, each base needs a check of touch, focus and the on-screen keyboard. No base was checked there.

D5How do card rules test the fields?Recommendation: small JSON tests, no script. Default: JSON tests
Context

Ui.Classify tests fields: two options yes and no, a default, the needs. The rules must be data (P11).

Options
  • A: JSON tests: exists, is, equals, count (tab 2, V5).
  • B: an expression language, for example JsonLogic.
Recommend

A. Four tests cover the variants of today. A schema can check them. JSON tests need no script engine on a phone.

D6Do overlays change the URL?Recommendation: no; overlays live only in the stack. Default: no
Context

Sheets and the speed dial become stack entries (tab 3). The browser Back key must close them. A URL for each overlay makes deep links to a half-done answer.

Options
  • A: no URL change; the navigator catches the browser Back for an open overlay.
  • B: a #sheet fragment for each overlay.
Recommend

A. A link opens a page, never a half-open sheet. The tray has no address bar. On Android, the Back button calls the same Back(). In a browser, Back needs a history entry for each open overlay, so option A has a cost there.

// The only native contract. The tray state machine calls it.
public interface IHostWindow
{
    Task Show(Place place);        // ends on the "shown" window event
    Task Hide();                   // ends on "hidden"
    void UseSize(PageSize size);   // from its own root only (P8, Places G5)
    event Action<HostInput> Input; // click, drag, key: to the trace
}
  • One class for both windows: DPI, display change and exit are written once (Places G8).
