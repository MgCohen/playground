The spec is a quest. The set is a party of heroes. Each line of the set is one hero.

- A party has a tag if one hero or more has that tag.
- The cost of a party is the sum of the costs of its heroes. Add the numbers one by one.
- A stat of a party is the sum of that stat for all its heroes. Add the numbers one by one.
- A hero that the quest calls "not free" must not be in the party.
- If the input has many parties, each under its quest id, the rubrics are about all parties together. "none" means no party for that quest.
- Use only the heroes in the set. Do not add a hero. Do not use what a hero name suggests: use only the listed fields.
- If a rubric needs a field that the set does not show, the verdict is false. Give the reason "field not shown".
