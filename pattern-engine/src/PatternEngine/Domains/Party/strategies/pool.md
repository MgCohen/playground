Pool. Plan all quests together. One hero can go on one quest only.

1. Find the scarce heroes: a need that only one or two heroes can cover, inside a budget. List them for each quest.
2. Give each scarce hero to the quest that needs it most. Then complete each party with the cheapest other heroes.
3. Add the cost of each party yourself, and the total cost of all parties.
4. Ask for a grade of each party with its quest, and of the full assignment in the same turn.
5. If a remainder is not empty, move or change a hero, and ask for the grades again.
6. Commit the assignment with the smallest total cost where each remainder is empty.
7. If no assignment can make all rubrics true, commit null ("none") for each quest.
