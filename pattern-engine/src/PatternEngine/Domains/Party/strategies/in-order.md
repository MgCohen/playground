Quests in order. Do each quest alone, in the order of the specs.

1. For the first quest, find the cheapest party with an empty remainder. Ask for grades as necessary.
2. For the next quest, use only heroes that are not in a party of an earlier quest. Find the cheapest party with an empty remainder.
3. Do not change the party of an earlier quest.
4. If no party is possible for a quest, that quest gets null ("none").
5. Commit all parties together.
