Compare. For each quest, build some different valid parties, then commit the cheapest.

1. Make 3 to 5 candidate parties. Start each candidate from a different first hero. Prefer cheap heroes that each cover one need.
2. Add the cost of each candidate yourself. Do not use a candidate over the budget.
3. Ask for a grade of all candidates in one turn.
4. Fix each candidate that has a remainder: change one hero, and ask for a grade again.
5. Commit the cheapest party with an empty remainder.
6. If no party can make all rubrics true, commit null ("none").
