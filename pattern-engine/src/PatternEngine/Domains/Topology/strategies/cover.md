Cover. Build one set of patterns step by step.

1. Start with the pattern whose "use when" matches the main job of the request. Choose the variant whose text matches the request.
2. Ask for a grade of the set.
3. If the remainder has io or a set check, add a pattern whose ports give the missing type, or that connects the set. If the remainder has a job, add the pattern that does that job. Ask for a grade again.
4. Do not grade a set that was graded before.
5. If the remainder is empty, commit that set.
6. If no pattern of the catalog can close the remainder, follow the Gaps section of the input.
